# Data Safety — respostas preparadas

Estas respostas devem ser revisadas contra o AAB final antes do envio.

- O app coleta ou compartilha dados obrigatórios: **Não**.
- Dados coletados: **Nenhum**.
- Dados compartilhados: **Nenhum**.
- Processamento apenas no dispositivo: hábitos, sessões e preferências.
- Conta obrigatória: **Não**.
- Criação de conta: **Não existe**.
- Exclusão de dados: disponível dentro do app em **Sobre o Aevum → Apagar todos
  os dados**.
- Dados em trânsito: não aplicável, pois o app não transmite dados.
- Anúncios: **Não**.
- Analytics/rastreamento: **Não**.
- SDKs com coleta: **Nenhum**.
- Público infantil: **Não; público declarado de 18 anos ou mais**.

Links externos opcionais só são abertos após ação explícita do usuário. Eles não
são SDKs incorporados e ficam ocultos quando não configurados.
